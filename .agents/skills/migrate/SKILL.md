# マイグレーションを適用する

直前の `git pull` で増えたエントリをすべて、適用するかユーザーが飛ばすと判断した状態にします。

1. 直前の `git pull` で増えたエントリを特定します。

   ```sh
   git diff ORIG_HEAD HEAD -- MIGRATIONS.md
   ```

   `ORIG_HEAD` は直前の pull しか指さず、変更のない pull や `git reset` でも変わります。差分が空のときや、複数回 pull したときは、`MIGRATIONS.md` の日付を見て、どこまで適用したかをユーザーに確認します。

2. `~/.config/mise/conf.d/profile-*.toml` で有効なプロファイルを確認し、このマシンが対象のエントリに絞ります。
3. 各エントリの手順と副作用を示し、適用するものをユーザーに確認します。現在のリポジトリの状態と合わないものや、適用済みと思われるものは、その理由も示します。
4. 古い順に実行します。失敗したら、そこで止めて報告します。
