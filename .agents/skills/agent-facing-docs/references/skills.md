# Skill

## description

`description` には、何をするかと、いつ使うかを書く。

悪い例:

```yaml
description: Pull Request の作成・更新・レビューを支援する。
```

良い例:

```yaml
description: Pull Request の作成・更新・レビューを支援する。Pull Request を作成・更新・レビューするときに使う。
```

異なる実行分岐を扱う場合は、それぞれを判別できる呼び出し条件を書く。

ただし、条件を網羅的に列挙せず、各実行分岐を判別するために必要な代表的な条件に絞る。

## Skill を分割する

Skill は、ファイルサイズではなく、独立して呼び出す必要がある単位で分ける。

一つの呼び出しから分岐する実行経路は、同じ Skill にまとめ、必要に応じて参照ファイルへ分離する。
