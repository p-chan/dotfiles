# Credits

このスキルは [Matt Pocock](https://github.com/mattpocock) の [`pr`](https://github.com/mattpocock/skills/pull/1120) スキルを元にしている。

概要セクションの図の一覧と配置の指針、証拠セクションの Before / After、危険性セクションの可逆性（原文では one-way door と two-way door）と影響範囲の考え方は、`pr` からほぼそのまま取り入れた。

`pr` の概要セクションは、[Dex Horthy](https://github.com/dexhorthy) の [`show-me`](https://github.com/humanlayer/skills/blob/main/plugins/show-me/skills/show-me/SKILL.md) スキル（HumanLayer）を元にしている。
