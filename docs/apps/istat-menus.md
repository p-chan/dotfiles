# iStat Menus

- [iStat Menus の設定ファイル](https://start.1password.com/open/i?a=LM5F3GUMXZESHA52XDBWU2IBH4&v=qmldmb6wi6rv7qu5sxemwffyv4&i=tme5ajhzmclm76utvqtcvw43ci&h=my.1password.com) をダウンロードする
- メニューバーから **File / Import settings...** をクリックし、`iStat Menu Settings.ismp7` を選ぶ
- メニューバーのアイコンを **CPU & GPU**、**Memory**、**SSD**、**Sensor** の順に並べる
