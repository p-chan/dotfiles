# iStat Menus

- Download [iStat Menus Settings](https://start.1password.com/open/i?a=LM5F3GUMXZESHA52XDBWU2IBH4&v=qmldmb6wi6rv7qu5sxemwffyv4&i=tme5ajhzmclm76utvqtcvw43ci&h=my.1password.com)
- From the menu bar, Click **File / Import settings...** and Select `iStat Menu Settings.ismp7`
- Arrange menu bar icons in the following order: **CPU & GPU**, **Memory**, **SSD**, and **Sensor**
