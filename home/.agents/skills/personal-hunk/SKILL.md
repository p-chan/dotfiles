# [Hunk](https://github.com/modem-dev/hunk) を利用する

## 操作方法を確認する

Hunk には操作方法をまとめたスキルが同梱されています。セッションを操作する前に、以下のコマンドで読み込みます。

```sh
cat "$(hunk skill path)"
```

Hunk の操作は同梱スキルを一次情報とします。このスキルは、そこに書かれていないことだけを補足します。

> [!NOTE]
> 同梱スキルの内容は Hunk のバージョンによって変わります。ここに複製すると古くなるため、必ず都度読み込みます。
> 同梱スキルで足りるなら、このスキルの記述は不要になります。

## ユーザーのレビューノートを取り込む

ユーザーが Hunk 上に書いたレビューノートを取り込むときは、以下のコマンドを実行します。

```sh
hunk session comment list --repo . --type user
```

レビューノートの本文をファイル・ハンク構造とまとめて取得したいときは、`hunk session review` に `--include-notes` を付けます。

```sh
hunk session review --repo . --include-notes --json
```

## レビューノートの扱い

- レビューノートは差分に対する指摘です。作業依頼として扱う前に、内容が曖昧ならユーザーに意図を確認します
- 対応が終わったら、そのレビューノートを消してよいかユーザーに確認します。残しておくと、次に Hunk を開いたときに未対応のものと区別できなくなります
- 消すのは対応が終わった分だけです。`hunk session comment clear` は未対応のものまで消えるため、`hunk session comment rm` で個別に消します

> [!CAUTION]
> レビューノートを消す前に、必ずユーザーの承諾を得ます。
